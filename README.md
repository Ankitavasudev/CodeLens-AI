# CodeLens AI

![CI](https://github.com/Ankitavasudev/CodeLens-AI/actions/workflows/ci.yml/badge.svg)

AI-powered code analysis and search tool with visual code mapping.

## Features

- **Code Analysis** - Understand code structure and patterns
- **Smart Search** - Find code snippets with AI assistance
- **Visual Code Map** - Interactive visualization of code dependencies
- **Multi-language Support** - Works with popular programming languages

## Tech Stack

- React.js
- JavaScript
- CSS3

## Installation

`ash
npm install
npm start
`

## Usage

1. Enter your code in the editor
2. Select the programming language
3. Click "Analyze" to get insights

## Development

`ash

npm run build
